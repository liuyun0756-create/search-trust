# P5 页面检查保存与恢复实施清单

依据：已批准的 `2026-10-23-p5-page-check-persistence-design.md`。
范围：内部授权、独立任务、不可变结果、一次领取和恢复。无公开入口、派发、收费变更、真实网站访问或正式迁移。

1. 新增选择/任务/历史摘要契约；重验身份、摘要、计划、时间和状态组合。
2. 新增有界私有仓储及单次执行器；保存不确定时只恢复保存，不重新采集。
3. 新增第 68 个迁移：Case → 报告 → 任务锁；最新来源检查；队列/租期过期；结果与完成状态原子提交；拒绝直接写入与历史覆盖。
4. 扩展测试用本地 RPC 适配器，增加模拟传输与真实隔离数据库的并发、篡改、权限、版本变化、取消、失联、过期和恢复测试。
5. 跑后端 fast、原生 PostgreSQL/Redis/ARQ 全套、11 个旧契约检查，修复本批问题。
6. 对照修改前基线核查文件范围，更新验收、台账和主计划；P5/P6 保持未关闭。
