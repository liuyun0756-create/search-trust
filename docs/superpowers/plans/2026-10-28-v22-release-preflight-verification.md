## 本轮实际代码变化

1. 复核和首次服务仅阻止新逻辑收费任务，已有逻辑任务使用原 ID 恢复。后台 worker/结算逻辑不改；没有把暂停当作退款。
2. 新复核 UI 明确暂停状态；不新增自动分析、轮询扣点或新请求身份。
3. 扩展安全哨兵范围及 vault 独立 key 扫描，结果只报告数量和脱敏命中位置。
4. 添加暂停处理器/配置、UI 身份保持和扫描回归；同步直接调用处理器的隔离数据库夹具。修正开发输出忽略和报告键盘阅读；交互测试等待身份就绪及 useEffect 完成后的实际焦点，不删减断言。其余主线实现和迁移保留。

最初针对性红测：9 failed / 35 passed，覆盖已知暂停和 marker 缺口；修复后针对性 47 项通过。再加入 UI 暂停交互回归后，纳入完整前端测试。
