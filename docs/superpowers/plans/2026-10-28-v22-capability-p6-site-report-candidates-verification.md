# P6-01 首批候选报告提取与完整预览验收

日期：2026-10-28。状态：**本地候选展示完成，公开站点同步和真实发布验收未完成**。

## 产物

- 后端 `scripts/export_v22_site_candidates.py` 调用实际 public/service 生成器；输入来自受控合成来源工厂，不导入手写报告或调用真实供应商。
- 获客报告：1 个发现、2 个来源值、1 项行动；服务报告：12 个发现、38 个来源值、3 项行动。服务报告上一版本摘要必须等于这份获客报告的完整摘要。
- 独立零行动诊断：1 个发现、3 个来源值、0 项行动，保留诊断、限制和“完成分析消耗 1 点、不返还”。
- FE 先验证正式契约，再沿用实际交付投影并按显示字段提取。内部账户、Case、任务、快照、绑定和输入清单不进入候选显示 JSON，证据引用改为局部编号。没有伪造批准或实施记录。
- 复用正式 `CapabilityReportDocument`；组件仅将输入类型缩小到实际读取字段，没有改变已上线渲染行为。离线阅读器提供三项切换、键盘导航、固定目录及内部滚动；手机端无横向溢出。
- `output/site-report-preview/index.html` 是自包含离线预览，浏览器打开即可运行。无公开路由、登录、远程字体、埋点或收费操作。预览只读，未接入生产营销页面。
