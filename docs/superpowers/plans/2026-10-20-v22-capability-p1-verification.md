## 已验证的不变量

- 引用必须存在，观察时间与快照一致，行动引用真实发现，依赖在前；拒绝重复、孤立和循环引用。
- 业务确认与采集证据分开；首次服务不能携带虚构历史，获客不能携带私有来源。
- GSC、GA4、公开 GBP 的匹配/健康/时效守卫保留；官方 GBP Performance 可选。拒绝零竞品、缺 GA4、失效快照、撤销授权、跨 Case 与错误校验值。
- 正常零行动报告的契约声明消耗一点、不返还。旧任务技术失败返还、赠送、价格和幂等规则没有改变。
- 冻结不另扣点：测试先建立一个已预留任务，重复冻结后余额仍为 4、该工作流只有一条 -1 记录。不是实际付款或新入口扣点验收。
- 候选报告保存锁定任务并检查 run generation；失败任务或错误代次不能写入新结果。精确重放返回原记录。
- 候选报告保存尚不进行成功挂接与账本消费结算。P2/P3 必须将新结果终结、回调和一次性结算接入受保护的原子流程后，才能开启新收费入口。
- 修订只允许叙事和已有行动；不允许证据/指标/新行动 ID。原样批准和零行动批准合法；旧期望修订返回 40001。
- 投影拒绝草稿、错误来源摘要或归属；原始事实不被覆盖。实际客户/PDF/分享仍待 P2 接入同一批准版本。
- Python 已解析模型再次使用时重验嵌套输入，防止解析后修改绕过校验；前端验证不修改输入。
