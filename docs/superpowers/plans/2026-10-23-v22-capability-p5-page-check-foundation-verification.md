## 本批交付

新增独立、不可变的计划/观察/比较契约，绑定所有者、Case、批准报告/交付、实施修订、行动、业务范围和检查条件。准备阶段复用实施记录验证；执行阶段重新验证计划摘要，不把摘要当授权凭据。未新增数据库授权读取器，未来调用方仍须读取真实授权来源。

受控获取最多 robots 和目标页面两次 GET，复用 DNS 固定传输；仅同一已确认主机、HTTPS 默认端口、无凭据/查询参数。片段不发往服务器。首版不跟随重定向，不抓全站，不执行 JS、不提交表单或跟随联系链接。

检查指定短语、同站链接、锚点，分别返回 observed/not_observed/unable_to_check；不返回原始 HTML、页面全文、输入框值、任意头部或异常原文。只有同一检查计划、严格先后时间的成功观察可比较；没有旧依据为首次观察，条件命中变化不等于实施全部完成或 SEO 效果。效果结论始终为空、因果资格始终 false。

## 自审修复与保守限制

1. JSON 数组读回转成不可变 tuple，保留内部元素的严格验证；避免只冻结外层对象。
2. 标题、隐藏字段、脚本、模板、表单输入值不作为正文证据；不支持的标记区段、旧式纯文本标签和超深/超多节点明确无法检查。
3. robots 仅支持可可靠处理的字面路径规则。包含通配符或结束锚点的 Allow/Disallow 规则本批停止检查，不猜测语义；冲突时不利用首个 Allow 绕过更具体 Disallow。为保守处理，所有组的显式 Disallow 和最大延迟均遵守，可能拒绝本可访问的页面。这是可用性限制，不宣称完整 robots 规范兼容。
4. 不支持 `<base href>` 的页面，避免错误推断相对链接去向；不声称静态解析等同浏览器渲染，也不声称所有挑战页面均可识别。
5. 仅保存内容摘要和所选条件结果；内容摘要变化本身不生成“实施变化”。
