# P5-02 比较窗口与描述性资格基础：本地验收

## 1. 范围与调查结果

依据用户已确认的 P5 总体方案继续实施；本批设计在 `../specs/2026-10-22-p5-comparison-foundation-design.md`。**不宣告 P5-02 或 P5 全部完成，不打开收费复核。**

代码调查确认：现有 GSC/GA4 各有两个 90 天周期及逐日行，但页面、查询等明细并没有日粒度交叉表。GA4 当前只过滤 Case 主机，不过滤自然搜索渠道，也不保存可证明数据完全处理结束的水位和完整历史事件定义。不能切分 90 天页面汇总当 28 天，也不能合并独立维度构造“页面×设备”，或把 GA4 总会话叫自然搜索访问。

Google 一手资料核对用于限定适配器，而非引入经验性效果阈值：[GSC query](https://developers.google.com/webmaster-tools/v1/searchanalytics/query) 说明源日期时区、日期缺行、查询维度/最终数据及行限制；[GA4 expectations](https://developers.google.com/analytics/devguides/reporting/data/v1/reporting-data-expectations) 说明估算、采样/阈值/other 元数据和精确查询范围；[GA4 freshness](https://support.google.com/analytics/answer/11198161?hl=en) 的处理延迟不作为本产品的最终完整性证明。本批没有真实供应商调用。

## 2. 已实现

### 后端内部计算

- 严格输入/结果契约，规则版本 `v22_comparison_descriptive_v1`；独立新增契约目录，旧 capability/implementation/runtime 不改。
- 每个请求选择某份已保存实施修订中的行动，绑定完整记录摘要、来源快照摘要及评价时点。结果保存精确 ImplementationReference、范围、窗口、输入/结果摘要。
- 默认前后各 28 天，可选择 7/14/28/90 天。将完整“实施日”区间转换到来源时区，排除所有重叠日期；不凭日期猜实施时刻。DST、闰日、跨年、跨时区两天重叠和本地不存在日期有定向测试。
- 复用现有快照摘要、资源/覆盖范围及健康重算校验。其它 Case、伪造摘要/健康、未来采集时点、重复日期等是非法输入，不伪装成一般“数据不足”。内部算法不是新授权入口，后续仍必须由所有者读取器验证权限和冻结清单。
- GSC 属性级逐日数据只有完整观察每一天、来源/绑定相同、最终数据和当前观察有效时才计算。页面/查询/设备/国家要求完整精确周期与确认的聚合方式；截断、缺行、URL 不在两期内、90 天和 28 天不一致都不补零、不外推。
- 支持已完成的历史快照作为基线，其后自然过期不重写旧数据；新观察必须有效。来源可用日期 `data_cutoff` 与实际参与计算的 `used_through` 分开保存。等待/不足/不可比时实际使用截止为空。
- 点击、展示保留绝对和相对差值；零基线相对值为空。CTR 从点击/展示推导，保留百分点差异，不直接平均日 CTR；零展示率为空。
- `waiting`、`insufficient`、`not_comparable`、`comparable` 均有原因代码。最后一项仅表示所支持的 GSC 描述值可对齐，**不代表统计样本充分或效果有效**。
- 所有结果 `effect_eligibility=pending_metric_specific_calibration`、`effect_conclusion=null`、`causal_attribution=false`。多个行动、未知/已报告同期改变、季节性和属性整体数据局限始终保留。
- GA4 当前适配器对未采集渠道、不同主机/时区、采样/阈值/other 限制、配置改变或完整性/事件历史待核实输出不可比。不会汇总日会话估计成任意周期“精确会话”，不输出 GA4 效果差值。

### 免费日历预览

已保存实施记录下显示窗口长度及“前窗口 → 排除实施日 → 后窗口”，默认 28 天，源时区未核实时明确为实施时区规划日期。

- 只使用已保存修订，不读取正在编辑但未保存的日期；保存成功后更新依据，取消实施标记后不显示预览。
- 日历未走完显示等待；走完也只显示来源检查待完成，不写“数据就绪”。
- 明确来源时区不同可能多排除一天，以及数据范围/完整性/测量仍需核实。
- “重新检查日历”仅更新当前时间，不请求数据、不建立任务、不扣点、不调用比较算法或收费复核。

未新增迁移或公开比较 API，没有修改实际开关。页面沿用默认关闭的 capability + implementation 双入口保护；原报告、批准修订、PDF 和分享不变。
