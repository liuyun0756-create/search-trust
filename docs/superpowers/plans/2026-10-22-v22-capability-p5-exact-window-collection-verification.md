# P5 精确窗口取数基础：本地验收

依据用户继续执行授权及已确认 P5 计划。设计：`../specs/2026-10-22-p5-exact-window-collection-design.md`。

## 完成本批范围

现有普通 GSC 同步固定采集两个相邻 90 天区间。其页面、查询、设备、国家汇总不能拆分成实施前后任意长度的汇总，本批补上精确取数基础，而非放宽比较资格。

- `GscProvider.collect_periods` 复用现有固定 Google 端点、规范化、错误清洗、20 秒请求期限、响应字节限制及成本记录。要求两个实际 date 区间、等长 1–90 天、前后不重叠；非法输入在网络访问前拒绝。普通 `collect` 保持原来的两个 90 天区间及 12 次请求行为。
- 独立 `comparison_collection` 从已保存且摘要正确的实施记录生成 7/14/28/90 天计划，绑定所有者、Case、报告、交付版本、实施修订、行动及来源绑定/资源。按 GSC 时区排除完整实施日期；跨时区可能排除两天。时间和来源须由内部调用方提供并独立授权，摘要不是所有权证明。
- 后窗口未结束时只返回 waiting，不请求供应商、不占用请求次数，也不自动安排稍后采集。窗口结束仅表示可尝试采集，不保证数据完整。
- 精确采集必须传入现有成本账本；两个区间各六个视图，最多 12 次尝试，同一账本重试不能增加预算。继续使用 web/final、当前行数上限，不自动分页、重试或拼接维度。整批有 240 秒期限，失败/取消不交付部分成功结果。
- 返回带专用用途标签的比较采集封装：计划、规范化 GSC 内容、健康判断、来源摘要和封装摘要。验证资源与日期绑定。它不是已经保存并获授权的 TrustedFirstPartySnapshot，不自动进入现有来源目录或最新普通同步。
- 缺失日期、截断、目标行缺失和聚合不一致均保留。受控数据接入既有比较器的测试显示：精确页面/查询等范围可以输出描述性数值；不完整范围继续不输出差值。效果结论仍为 null，GA4 和指标校准限制未改变。

核对了 [Google Search Analytics 官方接口](https://developers.google.com/webmaster-tools/v1/searchanalytics/query)：日期按 PT、首尾均包含；final 请求仅返回已最终确定的数据，但缺数据的日期可能被省略，明细并非保证全量。因此本批没有把“取数成功”当作“可比/有效”。

新增覆盖四种窗口长度、跨时区及夏令时、后窗口最后一秒/下一天边界、非法行动/实施修订篡改/日期范围、请求上限、供应商失败清洗、取消、采集封装篡改，以及精确页面/查询/设备/国家比较和缺日期/截断/缺目标/错误聚合。供应商响应均为合成测试材料，没有使用真实 OAuth 或外部采集。实际普通同步仍由原 worker 调用原方法。

本批没有前端运行代码或 UI 改动，没有重复浏览器截图/生产构建；不借用上批结果作为本批新验证。也没有新增数据库迁移、队列任务、公开路由、扣点、部署或实际开关变更。

## 边界与下一步

这是精确窗口取数基础，不是可点击的一键补数完成。下一步接所有者显式确认、持久化请求/恢复和独立用途存储；不能直接把非相邻的实施窗口保存成普通同步最新快照，影响现有 Findings。之后才能接比较来源选择。指标资格校准仍缺代表性样本，不拍脑袋设定点击/曝光门槛；GA4 完整性/事件历史、受控页面检查、新版 Verified 复核和一次分析扣点仍待完成。P5/P6 不关闭。

保留 D1：正常交付的零行动诊断消耗 1 点不返还，技术失败最多一次补偿。原有 review 生成阻止不变。
