# P5-03 第十一批：连续多轮复核验收

日期：2026-10-28。本批将已批准的 2.2.3 报告接回实施、证据冻结、独立决定、新一轮收费生成和审阅交付，完成本地连续复核链路。实际功能开关未开启，没有生产迁移或部署。

## 实现

- 独立有限 `v22_review_plan_basis_v1` 保存本轮业务/版本/计划、原始诊断、完整源报告摘要及自身摘要。原报告不改写，不伪造旧版本 manifest，不嵌套整份历轮输入和私人理由。
- 新版交付修订按原完整报告绑定；长工作说明沿用最多 4,000 字，批准后的文案传入下一轮计划。原始诊断继续明确为此前报告未重新核实的内容，不把上一轮页面/指标自动复制为新观察。
- 第 78 个迁移只调整内部计划来源、实施/页面/冻结/目录及生成基准校验。旧报告解析器保持原版本约束；原已保存报告、分享、收费和请求恢复语义不变。
- 报告页增加已批准计划选择、实施记录和下一轮证据入口；新草稿出现后，已有批准版仍可作为实施来源。后续通过现有免费实施/取证冻结/决定和单独 1 点生成确认继续。
- 前后端新增 `V22_MULTI_ROUND_REVIEWS_ENABLED`，默认关闭。前端还要求原生成、交付、实施、证据、决定开关；后端默认禁止解析后的新轮来源进入证据/生成准备，已冻结任务仍能按原输入完成。
- 零行动报告可保存空实施/证据/决定，下一轮仍交付诊断且成功消耗原预留 1 点。技术失败补偿、重复请求恢复和当前基准过期检查继续复用。
