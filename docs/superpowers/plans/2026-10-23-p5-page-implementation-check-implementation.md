## 顺序与验收

1. 新增严格且不可变的检查条件、来源绑定、观察和比较契约；校验摘要、大小、状态组合与时间。
2. 新增准备函数，复用实施记录验证，绑定业务范围/批准交付/实施修订；禁止从说明文字推断网址。
3. 新增独立受控检查器：复用固定 DNS 的 HTTP 传输，最多 robots+页面两次 GET、不跟随重定向；异常返回有限原因。
4. 新增静态 HTML 提取与精确条件匹配；不跟随链接，不保存全文，不确认效果。
5. 新增纯前后观察比较；身份、条件、版本和时间不一致不可比，无基线为首次观察。
6. 添加模拟网络与契约测试，覆盖设计中的十项验收；运行后端 fast 全量回归。
7. 自审代码和变更基线，修复发现的问题；记录测试实际结果，更新 ledger 和总计划。

## 明确不做

公开入口、队列注册、数据库持久化/迁移、真实网络请求、账本/点数变更、部署和实际开关修改。不为未改动的 UI 宣称浏览器验收。
