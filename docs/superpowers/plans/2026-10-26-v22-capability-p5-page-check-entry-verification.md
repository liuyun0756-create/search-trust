# P5 页面检查入口、限频与派发：本地验收

日期：2026-10-26。依据：[用户确认设计](../specs/2026-10-23-p5-page-check-owner-entry-design.md)、[实施清单](./2026-10-26-p5-page-check-owner-entry-implementation.md)。不是上线公告。

## 本批实现

- 报告实施记录区域新增独立页面检查面板，与指标比较并列加载；不依赖 GSC/GA4 数据和比较开关。选择已保存行动、明确 HTTPS 同站网址和 1–5 个文本/链接/锚点条件，再显式确认。
- 输入、实施修订和授权上下文变化后取消确认；展示原始版本、状态、检查时间、条件结果及最近 20 项历史。结果只说明静态响应，不代表功能、完整实施或 SEO 效果。
- 会话恢复键按账户、Case、报告、批准交付隔离；仅保存请求 ID 与必要选择。丢失回应后只 GET 原请求，刷新/历史/挂载不会 POST；未保存时只有用户明确点击才能用原 ID 和原选择重发。
- 独立严格共享契约、内部认证 API 和所有者 BFF。用户身份来自会话；创建前核对报告/交付与实施引用；同源写入、输入/响应大小限制、无缓存。前端不获得租期、完整来源报告、HTML、令牌或异常原文。
- 第 69 个增量迁移把限频放在 Case 锁保护的插入触发器中，旧创建 RPC 也不能绕过；来源校验先完成，相同请求恢复先返回，不重新计次。每 Case 滚动 24 小时最多 10 次，间隔至少 5 分钟，接受后即计次，包括随后失败/无法检查/过期。回滚和拒绝不计次，不额外扣点。
- 受控后台每批最多处理 20 个过期任务、派发 20 个已保存请求；清理只结束任务，不抓页面、不重排队。确定性专用队列 ID、一次尝试、105 秒包络、原 2 分钟租期。检查器的两次 GET/30 秒上限不变。存储客户端随 worker 关闭。

## 验证结果

- 新所有者入口与既有保存层定向单元测试：**112 passed**；其中新入口 52 项。
- 后端 fast 全量：**2,928 passed**（67.24 秒，禁用网络 socket）。
- 原生 PostgreSQL 17.10 / Redis / ARQ 最终全量：**145 passed，2,928 deselected**（192.64 秒），69 个迁移只应用于一次性隔离数据库。含新入口 18 项，覆盖交付版本共享限额、精确第十条过期边界、运行中后台过期和业务变化历史读取。3 条既有 ARQ `close` 弃用警告，不影响结果。
- 前端全量：**186 文件、2,077 项通过**；新增边界测试 34 项。
- 浏览器完整集成组：**21 passed**（含新增页面检查 5 项），覆盖原报告交付、首次服务、GSC/GA4、手动核验与页面检查。
- 类型检查、最终生产构建、12 组新旧双端契约导出检查通过；两仓库 `git diff --check` 通过。
- 既有安全产物扫描：48 个文件、0 项发现；没有加载真实 secret 值作匹配，因此不将该扫描表述为生产凭据审计。

所有网站 HTTP/DNS 与提供方响应均模拟；真实数据库、Redis 和 ARQ 只运行在一次性本地隔离环境。原生链路核对原报告/点数、已批准交付、实施记录及普通 Google 来源/同步数据未被页面检查执行改变。

## 交互与视觉检查

采用 React 实现规范：独立按需加载、事件中创建任务、账户/报告切换重置状态、取消过期页面请求。网页测试技能建议 Python Playwright，但当前 Python 环境无该库，采用仓库现有 Playwright 运行真实 React 组件与真实 BFF，拦截全部浏览器网络。

首轮浏览器检查发现并修正：下拉框显式可访问名称、状态公告不覆盖标题语义、404 恢复分支释放未读取响应。修正后全组 21 项通过。1280px 桌面与 390px 手机截图已查看，文字、表单、结果和历史可读，手机无横向溢出；键盘确认提交通过。

截图位于 `output/playwright/integration-results/page-checks-explicit-conse-db50f-tions-and-responsive-labels-chromium/page-check-desktop.png` 和同目录 `page-check-mobile.png`。

## 权限及开放边界

新代码开关 `V22_PAGE_CHECKS_ENABLED` 默认关闭。前端同时遵守原实施记录/能力门槛，后端同时遵守能力执行门槛；不依赖 Google 比较开关。没有修改实际环境配置、正式迁移、部署或访问客户网站。

数据库表和辅助函数权限没有放宽。限频 429 只传递严格验证后的有限原因与数据库时间，未知基础设施 429 保持不可用，不能伪装成用户额度。历史使用原授权绑定，不因当前来源变化而删除或重新检查。

**D1 不变：正常完成但依据不足仍交付诊断，消耗 1 点且不返还；原技术失败规则不变。** 页面检查不额外扣点，但不是无限检查或全站监控。

本批是页面检查所有者入口及派发的本地闭环，**不关闭 P5/P6 或总计划**。实施附件、GA4 实际可比资格、真实校准、新版收费复核和正式环境验收仍待推进。
