# P5-02 所有者免费比较入口：本地验收

沿用已确认 P5 方案和用户本轮执行授权。设计见 `../specs/2026-10-22-p5-comparison-entry-design.md`。本批将既有比较存储能力接入所有者页面，不启用收费复核或效果结论。

## 本批完成

- 已保存实施记录下新增显式打开的免费比较面板。选择行动、7/14/28/90 天窗口（默认 28）、GSC/GA4、单一范围、前后来源及同期变化；不会从浏览器接受实施记录正文或来源正文。
- 只列本 Case 当前授权的来源元数据，最多 50 条；过期历史基线可用，当前来源须新鲜且为绑定最新观察。界面展示资源、覆盖区间与采集时间，移动端保留完整来源说明。没有来源也可保存等待/不足状态，不补零。
- 新增第 62 个增量迁移 `20261022130000_open_v22_comparison_context.sql`：服务角色专用、只读目录，检查所有者及已完成 Verified/已批准交付资格，列最新实施引用和当前交付最新 20 次比较。浏览器数据库角色无执行权。
- Next 所有者 API 根据登录用户及路径构建请求；POST 校验同源、JSON、20KB 请求预算，关闭式 selection 解析，禁止注入用户/来源正文。内部地址检查、不跟随重定向、30 秒期限、150KB 回复预算及错误清洗；返回不缓存。
- 后端内部 API 要求内部认证和默认关闭的比较/能力执行开关。前端还要求既有实施记录与能力分发开关。实际环境开关未改。
- 新检查校验上下文读取时最新实施引用；若之后发生修订，已选定的不可变版本仍是依据，不宣称保存时强制读取最新版本。旧比较重试先恢复原结果，不因当前修订或 OAuth 撤销而重写。
- 结果按固定来源时区展示 before / excluded / after；符合资格的 GSC 显示 clicks、impressions、CTR、绝对及相对差值，CTR 用百分点。零分母保留不可计算说明。状态和限制用可读说明，来源内部限制代码不直接展示给用户。
- 每次结果带实施修订、采集时间、可用日期和实际使用截止日期；保留历史，刷新可重新打开。响应不确定时原选择保留同一个比较 UUID，避免重复保存；改变选择则开始新检查，不自动重试或轮询。
- 后端从存储重算并校验；前端验证独立 owner-view schema、目标绑定和结果摘要。仅投影结果，没有规范化来源正文、令牌或用户备注。

比较不新增分析任务，不改余额/账本、原诊断、交付版本、PDF 或分享，不调用供应商。效果资格仍为 `pending_metric_specific_calibration`，结论为 null，因果归因为 false。GA4 完整性/事件历史未验证时不发布前后值。整项 P5/P6 尚未完成。
