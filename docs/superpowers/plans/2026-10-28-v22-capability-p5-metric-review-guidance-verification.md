## 找到的问题与处理

1. **Method 并行偶发失败**：隔离副本无源文件改动时仍复现，trace 记录另一 worker 首次打开目的页面时触发 Fast Refresh/整页重载，刚选择的 tab 状态丢失。新增仅本地的浏览器全局准备步骤，在交互测试前请求编译 `/framework`、`/sample-report`、`/cases/new`。未改 Method 产品交互、未强制点击、未添加重试或删除断言；随后 9 项定向和完整 84 项双并发通过。只将已观察到的冷编译问题记为解决，不声称测试永远不会波动。
2. **GA4 限制文案映射**：原 sessionReason 是字典，初次组件接入按函数调用导致失败；已正确按键读取，未知限制使用保守提示。对应缺值/限制组件测试通过。
3. **生成 TypeScript 类型差异**：旧工作区生成类型对受限数组展开为元组，报告类型为较宽数组；新共享阅读辅助采用报告事实类型，可接受原工作区事实。测试 JSON 经生成夹具校验后显式进行类型断言，未修改历史契约或放宽运行校验。
4. **开发生成类型残留**：并行开发服务器结束后隔离目录 `.next/dev/types` 留有截断的生成文本，独立 tsc 首次失败。将该临时生成目录移出源码根保留检查，使用 `next typegen` 重新生成，最终 tsc 通过；实际工作区和业务文件未据此删除或绕过检查。
5. **测试配置/截图定位**：实际页面测试最初缺少显式 loopback URL，被原本的 E2E 防护拒绝；修正隔离进程配置，没有绕过防护。截图恢复隐藏 banner 时用包含隐藏节点的定位，未改变产品行为。
