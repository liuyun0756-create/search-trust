# P5-03 第九批：复核报告审阅与交付

沿用用户授权：在第八批正式 2.2.3 报告上接入所有者审阅、批准、PDF 和固定版本分享。使用现有绿色私有工作区视觉，以文档阅读为中心，右侧提供明确的交付操作；移动端顺序阅读。不改分析、扣点或生成入口。

## 状态与编辑

原报告不可变。独立交付修订保存 title、summary、client_note 和原有下一步行动的 title/target/steps/completion/review；行动 ID、顺序和材料保留，事实及 SEO 内部决定不能通过交付编辑改写。草稿不允许新建链接或下载客户 PDF，批准需明确勾选审阅确认。零行动可以批准完整诊断，不补行动。

保存使用请求 UUID + expected_revision，数据库事务内锁报告并检查最新修订。相同请求恢复相同结果，不再插入；同 ID 异正文冲突；并发旧版本冲突。未知响应时界面保留原请求，允许核实同一次保存，未核实前禁止改变请求另存。原报告和点数不变。

## 交付

新 PDF/链接要求最新保存修订已批准。在线分享固定 revision_id，后续草稿或新批准不改变旧链接；复用既有 30 天有效期、最多 20 个活跃链接、撤销及片段 token 路径。公开解析仅返回白名单客户文档，不返回原报告、用户身份、内部理由或原始来源载荷。

网页、批准预览和 PDF 共用同一客户投影：批准说明、本期工作与选定窗口观察、下一步计划、限制。保留首次基线、缺失数据、仅描述性变化及不证明因果的说明。PDF 品牌沿用现有能力：本次下载可加姓名、客户名、Logo、页脚，保留 SearchTrust 标识；在线链接不继承临时品牌设置。

## 接入

新增默认关闭 `V22_REVIEW_DELIVERY_ENABLED`，同时依赖 capability dispatch。专用所有者 review 页面、修订 API、交付 API；Reports 列表加入已完成复核版本，普通报告链接跳转专用页面。分享解析增加 2.2.3 分支，旧路径保持。迁移仅隔离本地验证，不修改实际开关或部署。

验收包含 SQL 权限/幂等/冲突/批准与固定链接、零行动、私人内容排除、API 所有权/同源/体积保护、UI 保存恢复/移动端、真实 PDF 文本和页数检查。原子收费入口、派发、多轮输入适配仍待后续。
