# P5 页面实施核实：内部基础设计

日期：2026-10-23

状态：2026-10-23 用户确认书面设计；本批内部基础已实施并通过本地验证，参见 `../plans/2026-10-23-v22-capability-p5-page-check-foundation-verification.md`。公开入口和持久化不在本批范围。

## 1. 目标与已确认范围

回答“系统在指定页面当前观察到了什么”，为后续实施复核提供独立证据。
不把用户填写的实施记录、系统检查结果和效果判断混为一谈。

本批只交付内部契约、受控检查器、确定性解释与模拟测试。不新增公开 API、页面按钮、队列注册、数据库迁移、定时任务或收费路径；不调用真实客户网站，不部署，不修改实际开关。

正常完成但没有足够行动依据的诊断，仍交付并消耗 1 点、不返还。技术失败规则不变。本批不触达账本。

## 2. 选择的方案

采用“内部核实能力优先”：复用安全 HTTP 基础，在指定页面上检查明确、有限的内容条件，返回可追溯结果。

不采用只读旧快照作为当前核实，因为旧快照不能说明页面现在的状态；不直接新增完整用户入口，因为确认流程、运行成本和持久化恢复应在下一批单独接线。

## 3. 现有代码依据

后端根目录：`SearchTrust-RD`。

- `app/report_v22/implementation_records.py` 已验证报告、批准交付、实施修订和行动关系；`scope` 是自由说明文字，不是可信 URL。
- `app/report_v22/capability.py` 提供已确认业务范围、来源引用与严格版本模型。
- `app/collectors/site_inventory_fetcher.py` 提供 DNS 固定、逐跳公网及站点检查、超时和响应大小控制；不会独立执行 robots 检查，也不会拒绝全部非成功 HTTP 响应。
- `app/collectors/site_inventory_discovery.py` 提供 robots 解析；现有 `load_robots` 在部分异常下允许继续，不直接用作本功能的放行依据。
- `app/collectors/site_inventory_urls.py` 提供站点范围和 URL 规则；页面身份不可因通用规范化而合并不同路径。

不修改旧采集器的默认行为、旧来源摘要或旧报告契约。

## 4. 输入和权限边界

内部准备函数接收从可信存储读取的已完成 Verified 报告、已批准交付、实施记录、已确认业务范围及行动 ID。复用实施记录解析，核对同一所有者、Case、报告、交付修订、实施修订及其摘要。

本批不新增数据库读取器，调用方有责任提供已授权来源；不宣称纯契约校验等同数据库权限验收。缺失或不匹配的来源在任何网络请求之前拒绝。

目标页面作为单独字段输入，不从行动说明、scope 或备注自动提取。必须属于已确认业务站点；不允许切换到竞争对手、任意子域或未确认的新域名。首版只支持 HTTPS 默认端口、无凭据、无查询参数的公开页面；带片段的地址保留片段供锚点检查，HTTP 请求去掉片段。路径及尾斜杠不作猜测性合并。

业务网站尚未确认、目标仅存在于说明文字中、或需要带查询参数的页面，均返回明确的准备限制，而不是静默选择首页。

每次输入最多 5 个显式检查条件，条件 ID 唯一：

1. `text_present`：指定短语是否出现在可提取的正文文本中。
2. `link_present`：是否存在明确指定的同站公开链接；不跟随链接。
3. `anchor_present`：是否存在指定的页面锚点。

不使用大模型猜测“服务说明已足够专业”，不自动生成条件。条件来自可信调用方提供的结构化输入，仍属于待检查的要求，不属于事实。

## 5. 单次检查流程与预算

顺序：验证来源 → 验证目标和条件 → 检查 robots → 获取指定页面 → 提取有限事实 → 解释检查结果 → 生成摘要。

- 每次最多 2 个 HTTP GET：robots 和指定页面；并发 1；遵守现有限速，最低间隔 1 秒。
- 首版不跟随重定向：返回 `redirect_requires_confirmation`。不自动把新地址当作原行动页面，也不先抓取尚未检查 robots 的目标路径。
- 使用现有 DNS 固定传输和公网地址检查；禁止内网、回环、链路本地、保留地址及 DNS 重绑定绕过。
- robots 上限 256 KiB，页面上限 1 MiB；连接超时 5 秒、读取超时 10 秒、整体检查上限 30 秒（包括等待）。流式解码后同样受大小上限约束。
- robots 返回 404/410 可继续；有效 200 按解析后的规则判断。禁止、401/403、限流、5xx、网络错误、重定向或无法可靠解析时停止，不把未知权限当作允许。
- crawl-delay 在总预算内遵守；超过预算时停止并返回原因，不缩短站点要求。
- 本批支持字面路径 robots 规则；遇到 Allow/Disallow 通配符或结束锚点停止检查。为保守处理，所有组的显式 Disallow 与最大延迟均遵守，可能拒绝本来允许的页面，不宣称完整规则兼容。
- 页面仅接受成功的 200 HTML/XHTML。其余状态、无正文或不支持格式均为无法检查。
- 不执行 JavaScript、不加载图片或其他资源、不发 Cookie 或登录凭据、不提交表单、不点击联系按钮、不检查电话是否接通。
- 本批所有网络路径用模拟传输与模拟解析器验证；不做真实站点冒烟请求。

## 6. 提取与结果语义

静态 HTML 提取排除 script、style、template、noscript，以及明确带 hidden/aria-hidden 的子树；不宣称能判断 CSS 布局或浏览器最终可见性。

短语匹配只作 Unicode 规范化、大小写及空白归一化，不作同义词或语义推断。锚点匹配区分大小写；链接按明确的相对地址解析规则比较，不移除有业务意义的路径部分。外部、凭据、查询参数链接不进入保存结果。

每个条件分别返回：

- `observed`：当前获取的静态 HTML 中找到该条件。
- `not_observed`：成功检查当前静态 HTML，但未找到；不等于页面没有该内容，动态内容仍可能未覆盖。
- `unable_to_check`：访问、安全、政策、解析或来源条件阻止了有效检查。

HTTP 200 也可能是挑战页或登录页。识别到明确的密码输入、挑战或访问限制标记时拒绝作正常页面判断；未识别到标记不构成“页面身份已全面验证”的保证。所有结果保留“静态响应观察、未验证渲染与功能”的统一边界。

不输出整体 `implementation_confirmed=true`。全部条件 observed 仅表示所选静态条件被观察到；表单功能、发布审批、内容准确性、GA4 事件及咨询效果仍未验证。

## 7. 结果绑定、最小化存储和历史

独立版本契约 `v22_page_implementation_observation_v1`，保存：

- 检查 ID、所有者/Case/报告与批准交付引用；实施记录 ID、修订和摘要；行动 ID；业务范围版本与摘要。
- 规范化目标地址、观察时间、检查器规则版本、检查条件及结果。
- HTTP 状态、媒体类型、字节数、有限错误码和限制；内容摘要与整个结果的规范化摘要。

不输出原始 HTML、完整页面文本、任意响应头、Cookie、表单值、电话/邮箱列表或服务端异常原文。条件文本限制每项 200 字符，锚点 128 字符，URL 2,000 字符；拒绝控制字符。错误内容不能成为可执行指令或渲染 HTML。

本批只返回不可变值对象和完整性摘要，不实现数据库持久化；后续接线必须追加独立记录，不覆盖实施日期或既有报告。摘要用于完整性和身份绑定，不是身份签名。

## 8. 旧依据与变化判断

没有兼容旧观察时输出 `first_observation`，变化结论为空。现有 site inventory 快照不自动视为兼容的实施检查，因为检查条件和提取规则可能不同。

可选旧依据只接受由可信存储读取、摘要有效的同版本观察。比较前核对所有者、Case、报告、批准交付、实施修订、行动、目标地址、条件、规则版本及时间顺序。任何不一致输出 `not_comparable`，不静默丢弃旧依据后假装可比。

两次成功且身份一致时，仅比较每项条件的 observed/not_observed：新增观察到、当前未再观察到、保持一致。完整 HTML 摘要变化不能直接变成“实施完成”或具体内容变化结论。任一侧无法检查，相关条件不作变化判断。

无论结果如何，效果结论保持空、因果资格保持 false。不改动 GSC/GA4 数据资格。

## 9. 模块边界

拟新增后端模块（文件名可在保持职责不变时细化）：

- `app/report_v22/page_implementation_models.py`：严格输入、结果、版本和摘要。
- `app/report_v22/page_implementation_checks.py`：来源绑定、准备检查及纯比较解释。
- `app/collectors/page_implementation.py`：有预算的单次安全获取与提取。
- `tests/test_v22_page_implementation_checks.py`：契约、身份和解释测试。
- `tests/test_v22_page_implementation_collection.py`：模拟网络、安全、robots 和解析测试。

不注册路由、任务或调度；不在报告生成流程中默认调用。首次交付没有用户可触发的隐含网络路径。

## 10. 验收要求

1. 来源身份、批准版本或实施修订不匹配：零网络请求。
2. 内网/凭据/查询参数/不支持协议/跨站地址：拒绝；DNS 解析与连接目标保持绑定。
3. robots 禁止或无法确认：不抓页面；404/410 与允许路径可继续。
4. 重定向不跟随，超时、限流、5xx、非 HTML、超大响应分别给出有限原因。
5. 成功页面分别覆盖三种检查条件的命中和未命中；脚本、隐藏子树及 HTML 注入不成为证据。
6. 内容缺失不是效果失败；HTTP 错误不是内容缺失；链接存在不是联系流程可用。
7. 无旧依据为首次观察；旧依据摘要、条件、规则、时间或身份不一致不可比较。
8. 日期修订不改写历史观察；结果篡改被摘要校验发现；旧契约回归保持通过。
9. 检查结果不包含完整 HTML、表单值和任意异常正文；请求和响应均有预算。
10. 定向测试和后端 fast 回归通过；没有新持久化时不声称验证了数据库保存或恢复。没有 UI 修改时不声称浏览器验收通过。
