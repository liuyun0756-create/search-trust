# P5-02 逐指标复核判断与下一步核查

用户已在上一轮提出逐指标、可比条件、明确解释和下一轮计划衔接方案后授权“开始构建吧”。本文件记录该范围，不重新开启审批或自动提交。

## 调查结论

- [x] 原 GSC 阅读辅助已校验点击/曝光/CTR 的数学粒度，但正式复核事实区域只显示数字和限制。
- [x] GA4 有独立可读会话快照，处理完整性和历史测量口径仍未证实；关键事件不在当前 ActionFacts 的可发布值中。
- [x] EvidenceFacts 同时用于所有者证据审阅和决定工作区；可在这里衔接，而不重写生成报告、客户版、PDF 或分享。
- [x] 本地没有经授权、有完整来源与保留集的真实效果校准数据，不能据此生成充分样本阈值或统计显著结论。

## 实现

新增独立、确定性、版本化的 owner 阅读辅助，从已验证 ActionFacts 派生五项：曝光、点击、CTR、自然搜索会话、关键事件。每项展示自己的状态、实际前后值（CTR 保留两期分母）、绝对变化、限制和具体下一步。来源未选、窗口未完成、不可比、零分母、可描述、受限会话、未提供关键事件分别处理。数据结构只存规则代码及值，UI 负责专业且直接的文案。

状态优先级：缺来源 → 等待窗口 → 原来源限制 → 指标自身数学条件 → 描述性阅读。局部指标异常不能把整份报告当成成功；数据内部矛盾直接拒绝辅助，保留原审阅页面且提示重新核实。已有授权/原快照有效性由原入口继续执行，新模块不是认证边界。

点击与曝光展示绝对数量和相对变化；零基线不显示百分比。CTR 使用各期总点击/总曝光，不把点击阈值当 CTR 阈值。GA4 会话仅展示已通过原读取资格的快照数，保留 processing/measurement 限制。关键事件不从 sessions 推导，也不显示伪零；要求核实事件名称、计数方式、口径历史及完整窗口。未知限制仍使读者核查，不默认通过。

每项提供具体核查方向（需求/搜索组合、页面与查询、分母、测量/落地页、事件口径）。共同说明原记录实施日期及并行变化；不自动选 continue/adjust/observe，不自动付费取数或生成下一份报告。前后值来自原冻结事实，后续新增观察需走原入口。

复核工作区默认显示简洁指标卡和下一步，依据/窗口明细展开查看；原事实明细保留在可展开的来源区域。正式 SEO 报告页增加同一阅读辅助（客户出口不变）。颜色表达数据可读性，不表达成功/失败。移动端单列，details 可键盘操作。

## 约束与备选

通用百分比/最低样本阈值没有依据，拒绝；只改静态说明不能覆盖状态，拒绝；采用现有资格之上的逐指标判定和下一步解释。保留 effect=null / causal=false / calibration pending。另记录后续实证校准所需的数据字段、评价与保留集门槛，明确这不是已校准。

## 验证

Python 参考与 TypeScript 计算共享独立 schema/定向夹具；验证零、稀疏/大样本、相同 CTR 不同分母、无变化、等待/缺失/限制、来源口径、篡改值拒绝和旧事实不变。组件及真实浏览器覆盖默认五项、展开、键盘和手机；完整单测/构建/产物扫描，旧契约不变。无新表/付费路径，不重跑无关数据库迁移验收。现有 Method 并行测试另定位，不能通过删断言或重试掩盖。
