## 实现说明

### 版本及边界

- 新公开规则集为 `v22_capability_public_v8`，新服务规则集为 `v22_capability_service_v5`，报告版本为 `2.2.5`。现有静态/渲染输入版本继续使用原结构。
- 旧规则集继续走旧生成分支，不补写旧报告，不回填证据。没有标记的历史报告显示 `Unlabelled`，不从文字推断状态。
- 新报告每条发现必须有 `kind/status/coverage`。未知规则不能默认为事实，必须先注册映射。
- 用户已确认：`inference` / `recommendation` 的 `status` 固定为 `not_assessed`，展示保留类型。
- 覆盖范围仅描述该条发现引用的证据；不因为整个报告连接了某个来源，就把它标成该条发现“已查”。当前固定列出 site、gbp、serp、competitor、citation、gsc、ga4、rendered。没有引用的来源标为未查。
- 本任务不实施 P0-07 的行动过滤或行动排序调整。
- 第 6 条已按答复 1 实现：仅公开 v8 新增顶层 `contact_checks` 数组，每字段最多一条，直接取自本次 `SiteGbpFieldResult` 和配对。电话/地址/名称/服务区使用原状态映射；保留实际比对部分、遗漏部分和绑定证据。没有对齐结果时数组为空，不推断。
- `contact_checks` 不生成 finding、行动或排序输入。历史报告及服务报告不增加该字段；旧报告不显示新小节。文本来源标明 `based on text recognition`，渲染来源标明 `based on a rendered page`。结构化且没有遗漏部分时不加限定语。多个配对的组成部分按原记录去重保存，不扩展成完整地址匹配。

### 状态映射

| 输入或发现 | 新状态 |
|---|---|
| GBP `observed` | `confirmed` |
| GBP `returned_empty` | `not_detected` |
| GBP `not_returned` / `unsupported` / `request_failed` | `not_checked` |
| 对齐 `exact_match` / `semantic_match` / `partial_match` / 有资格比较的 `mismatch` | `confirmed`，仅限实际比对部分，范围随 `contact_checks` 展示 |
| 对齐 `site_missing` | `not_detected` |
| 对齐 `not_checked` | `not_checked` |
| 对齐 `not_applicable` | `not_assessed` |
| 旧对齐 `gbp_missing` / `both_missing` | 有原始 `returned_empty` 依据才是 `not_detected`，否则 `not_checked` |
| `market_site_domain_unobserved` | `not_detected` |
| 公开报告无行动依据的汇总记录 `public_assessment` | `not_assessed` |

### 客户文案（按中期检查答复 2）

`observed_fact` 原样保留，每条发现的具体观察保持可区分。仅非确认状态的 `judgment` 和 `impact_path` 使用下表；顾问仍使用原文。

| 状态 / 类型 | 客户 judgment |
|---|---|
| `not_detected` | Not detected in the checked sample. This does not show that it is absent. |
| `not_checked` | This could not be checked with the available evidence. |
| `not_assessed` + fact | The available observations do not establish an overall assessment. |
| `not_assessed` + inference | This is an interpretation to assess, not a confirmed fact. |
| `not_assessed` + recommendation | This is a recommendation to review, not a confirmed fact. |

`impact_path` 统一为 `No cause or business impact is established by this item.`。已删除 `Confirm the relevant details and checked scope before drawing a conclusion.`。不再整段替换观察文字，也不修改冻结证据或顾问原文。

客户证据来源示例：`serp` → `Search sample`；时间戳 → 原时间戳所在日期（不因时区转换跨日）。同一发现中多条证据的相同范围只展示一次。顾问原始文字、时间和路径保持原样。
