# P1-06 信任声明校验设计（待负责人确认）

**识别。** 在绑定且成功的 HTML 深度页中检查可见正文、页脚、徽章和图片 alt。复用 P1-03 的执照/资质抽取，包括原有长度、商家自述和否定语排除条件。评分须有数值与 star/rating 或 4.9/5 等评分格式。奖项须有 award winner、winner of、Travellers’ Choice 等明确获奖语义。Google、Yelp、BBB、Angi 等平台徽章须有受支持的链接目标和 review、accredited、profile 等上下文，或明确指向该平台商户页的品牌徽章。链接取同一锚点或明确同一徽章容器的关联锚点。排除隐藏内容、导航、推荐语、孤立图标和普通营销词。同文同链接去重，同一目标实体可合并展示并保留来源。执照只记录页面声明与号码。州执照库核验另立后续项。

**归属。** Google Maps/搜索只识别受支持的 HTTPS Google 域名和 URL 格式。解析 CID、ludocid、Place ID（含 query/destination_place_id）、Data ID，复用 P1-05 的规范化和 Data ID 转 CID，匹配已确认 GBP 分支。Yelp slug、BBB profile ID、Angi 商户 ID 只与同平台已确认键精确比对。可比键明确一致为“属于本商家”，明确不同为“指向他方实体”。键冲突或不可比、短链未展开、链接失效或无法解析均为“未检查”。只有“指向他方实体”产生问题。客户写“该评分徽章链接指向的商家资料与本商家不一致，建议核对”，网页、分享、PDF 净化。顾问显示原文、URL、命中键与已确认依据。归属结果只评价链接目标。
