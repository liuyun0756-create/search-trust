# P1-02：竞品 GBP 对比设计（2026-11-17，待负责人审）

本轮仅设计。负责人已确认第六次冒烟三竞品均有 GBP 与各30条评论，评论恢复、网站不可用两项前置已解除；不重采。维持3个已确认竞品，GBP比较不受其网站 partial 状态连带否决。

**1. 字段与来源。** C=`public_gbp.payload.record.fields`（客户现有v2）；G=`competitor.payload.competitors[i].public_gbp`；R=`competitor.payload.competitors[i].reviews[]`；CR=拟新增客户v3的 `public_gbp.payload.review_sample.reviews[]`。客户字段须 state=observed，双方沿用 P1-05 已确认分支及 D/P 身份门槛。

| 对比项 | 客户 / 竞品字段 |
|---|---|
| 类别 | `C.categories.value` / `G.categories`；只列返回集合，不猜主类别 |
| 评分、评论总数 | `C.rating.value`、`C.review_count.value` / `G.rating`、`G.review_count` |
| 近90天新增 | CR / R 的 `iso_date`，按评论ID去重后计数 |
| 最近评论日期 | CR / R 的 `max(iso_date)`，标“样本最近评论日期” |
| 店主回复率 | CR / R 的非空 `owner_response_text` 数 / 去重有效样本数；`owner_response_iso_date`仅溯源 |

**2. 样本口径。** 冻结评估时点T，90天为 `[T−90天,T]`；复用 newestFirst、最多30条。触顶且30条全在窗口内显示“至少30条”，不是全量新增；其他未完整覆盖的窗口也仅报已知下限，不推算全量。只有连续新到旧覆盖窗口或确认自然结束，才报精确数；任一日期不可判时，日期指标未检查，不填0。回复率明确标“样本可见回复 R/n（n≤30）”，分母不是总评论数；回复字段不可判时整项未检查，不能算未回复。n=0且已确认全量评论数为0时，90天数为0、日期/回复率不适用；其余空样本未检查。

**3. 三条比较门槛。** 按指标独立判断：客户可判且至少2个身份匹配、字段有效的竞品支持同一方向，才陈述观察差异；不足2个则比较未检查，仍可列单家已观测值。对应指标原始采样时点 `max−min≤24h`，不用缓存读取时间；来源时点不可追溯也未检查。评论需至少1条可判样本及可追溯排序/分页覆盖；失败、日期/回复解析缺口均不当0。下限区间重叠不排高低；不生成排名原因或自动行动。

**4. 客户评论与成本。** 提议 `V22_CUSTOMER_GBP_REVIEWS_ENABLED=false` 控制新模块及增量采集，关闭保持现有v14路径。复用 google_maps_reviews（newestFirst、4页上限、30条去重）；每报告新增1–4次，已有 checkpoint 命中为0；缺可用data_id时仅允许同一已确认分支最多1次详情解析，否则未检查。合计≤5次供应商尝试（含重试），耗尽不续采；不增加竞品、Firecrawl或LLM。按[官方价格](https://serpapi.com/pricing)（2026-11-17）Starter $25/1000，预算 $0.025–$0.10，含详情最多$0.125；属套餐摊销估算，非本账户实扣，未定价仍记unknown并记全部尝试。

**5. 暂不纳入。** 离线检查第五次 f4a76990 的已保存 checkpoint：三竞品 public_gbp 无照片数/服务项数，客户 photo_count 为 not_returned；因此本期不纳入两项，不记0、不新增试探调用，也不声称 SerpAPI 所有接口均不支持。

**6. 版本化提案。** 新增 v15规则集 / 报告2.2.10 / manifest v5、`gbp_comparison_v1`；客户快照v3保存评论样本，竞品快照v2补排序、分页完整性、字段可判性和原始时点。同步Pydantic/JSON Schema/TS及导出；新增迁移放行新组合，覆盖 freeze/store/hydrate/prepare、身份绑定触发器与审核/离线重判白名单。新checkpoint命名空间隔离；旧v1–v14生成分支、冻结证据和checksum不改，历史黄金/字节基线必须通过。

**7. 展示与验收。** 网页、分享页、PDF共用客户白名单：四列并排、采样日期、至少N条、样本分母及未检查原因；不带ID、规则ID、坐标、语言/设备或路径。顾问折叠区附分支标识、来源引用、原始时点、分页/排序与覆盖缺口。测试覆盖30条全在90天、跨窗口/时区、重复/坏日期、空样本、部分失败、24h边界、仅1竞品、下界不可排序、三端净化、关开关零新增调用及历史字节不变。
