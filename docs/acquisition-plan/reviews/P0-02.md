## 实现说明

### 统计口径

数据范围是 `public.capability_report_versions` 的全部报告版本；旧版 `public.reports` 不是能力报告，不混入这个分组统计。

| 字段 | 含义 |
|---|---|
| `report_count` | 能力报告版本数，不按 Case 合并 |
| `completed_reports` | 通过现有 `get_v22_completed_capability_report()` 完成及计费资格检查的报告数 |
| `ever_approved_reports` | 曾存在 approved 交付修订的报告数；任务要求的“已批准交付”历史口径 |
| `latest_approved_reports` | 最新修订为 approved 的报告数，避免把随后改回草稿的报告当成当前已批准 |
| `deliverable_approved_reports` | 当前最新修订已批准，且通过完成资格检查的报告数 |
| `shared_reports` | 曾生成至少一个分享链接的报告数；任务要求的“已生成分享链接”口径 |
| `share_count` | 分享记录总数，包含已过期和撤销记录，用于与报告数区分 |
| `active_share_reports` | 至少一个未撤销、未过期、绑定有效 approved 修订且通过完成资格检查的分享所对应的报告数 |

每份报告先独立计算状态，再分组，多个修订和多个分享不会把报告数乘大。有效分享依赖其固定修订，而不是最新修订；最新修订变成草稿时，历史已批准分享仍可能有效，脚本保留这一语义。

规则集字段不存在、为空或类型错误时归入 `ruleset_version: null`，不猜测版本、不归为 v5。数据库不可访问、缺表、权限不足、超时、输出缺字段或分组总数不符时，脚本非零退出并输出 `status: not_checked`，不会伪造零报告结果。

SQL 使用 `BEGIN TRANSACTION ISOLATION LEVEL REPEATABLE READ READ ONLY`，设置 30 秒查询超时，最后 `ROLLBACK`。仅返回规则集及汇总数，不返回客户信息、报告正文或分享 token。完成资格函数是现有只读 SQL 函数，定义见前端迁移 `20261020120000_settle_v22_capability_analysis.sql:17`；分享条件对应 `20261021150000_share_v22_approved_capability_reports.sql:53`。没有新增 RPC、授权或迁移。
