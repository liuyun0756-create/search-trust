| 类别 | 关键词、结构、最少内容 |
|---|---|
| 详细案例 | 独立正文段≥160字符，含project/case study及completed/installed/repaired/replaced/built之一，并含预算/客户/地点/前后等至少两种细节标志；泛泛“our work”不算。 |
| 作品展示 | 非导航标题为our/recent/latest/completed/additional projects、portfolio、photo/image gallery或our works（排除project management/delivery、FAQ、泛泛单数project）；相邻正文≥40字符且同一内容容器有≥2幅图或项目详情链接。仅导航链接不算。 |
| 资质声明 | 正文/页脚的执照标签及≥4位号码；或≥30字符的明确本商家we/our team/technicians等主体+licensed/certified/insured/bonded声明。排除否定、招聘要求、驾驶证、建议及他人声明，不验证证书有效性。 |
| 服务报价 | 正文≥15字符，from/starting at/price/service fee等与货币金额同段（价格信息可为单位价区间，不宣称是已承诺报价），或金额带per visit/hour等单位；排除评论、项目预算和优惠。 |
| 优惠 | 正文≥15字符，金额及off/save/discount/coupon同段；与服务报价分栏。 |
| 项目预算 | 正文≥40字符，project与estimated budget/budget及金额同段；与服务报价分栏。 |
| 目标城市 | 标题/H1/正文/页脚中的完整目标城市词；排除仅商家名及导航。全样本去重最多1个实体，不把提及次数当实体数。 |

全部比较均标inference；受限计数不排序，客户已观测到同类元素时不制造差距；客户负向不可证、竞品少于2家或时差>24h时未检查。10站命中逐项由实施者核对，记录规则误命中与无法判断，不改负责人truth。

资源边界沿用现有无依赖HTML树：单页1 MB、20,000节点、深度64。超限/未解析均只保留未检查，不用空命中冒充没有；作品元素数是不同展示区/声明的采样下限，不是项目数量。
